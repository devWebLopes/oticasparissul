# Skills — Óticas Paris Sul

Índice de habilidades técnicas, regras de negócio e ferramentas que os agentes precisam para operar neste projeto.

## Skills Disponíveis

| Skill | Descrição | Arquivo |
|---|---|---|
| **web-development** | Desenvolvimento frontend React, Tailwind, shadcn/ui, acessibilidade | [web-development.md](web-development.md) |

| **seo** | SEO, GEO e dados estruturados (JSON-LD, robots, sitemap, llms.txt) | [seo.md](seo.md) |

## Como Usar

Cada skill define:
- **Quando aplicar**: contexto e cenário de uso.
- **Regras obrigatórias**: restrições que devem ser seguidas.
- **Ferramentas**: pacotes, comandos e configurações relevantes.
- **Gotchas**: armadilhas específicas do projeto.

Os agentes especializados referenciam as skills apropriadas para executar suas funções.
